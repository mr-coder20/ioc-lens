# 🔍 IOC Lens (فارسی)

**کپی کن، نشان بده، در یک ثانیه بفهم.**
ابزار سبک و حریم‌خصوصی‌محور برای بررسی سریع IOC مخصوص تحلیلگران SOC، روی دسکتاپ و موبایل.

## چرا؟
هر تحلیلگر روزی ده‌ها بار یک IP/هش/دامنه را کپی می‌کند، چند تب باز می‌کند و نتایج را مقایسه می‌کند. IOC Lens همه‌ی این‌ها را به یک میانبر کیبورد یا یک اسکن دوربین تبدیل می‌کند.

## ویژگی‌ها
- جست‌وجوی فوری از کلیپ‌بورد یا میانبر سراسری
- OCR با دوربین/اسکرین‌شات
- تشخیص خودکار نوع نشانگر (IP، دامنه، URL، هش، CVE)
- **Privacy Guard**: نشانگرهای داخلی (IPهای خصوصی و ...) هرگز به سرویس بیرونی ارسال نمی‌شوند
- امتیاز تجمیعی **قابل توضیح** از چند منبع
- بدون بک‌اند، بدون تله‌متری؛ کلیدهای API در Keychain/Keystore
