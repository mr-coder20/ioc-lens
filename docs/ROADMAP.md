# Roadmap

Direction only. Scope will evolve.

- [ ] **v0.1 Desktop MVP** (Windows, macOS, Linux): fast clipboard lookup, several free sources, explainable verdict, Privacy Guard, local history
- [ ] **v0.2 Android**: share target, in-app scan, history
- [ ] **v0.3 iOS**: share extension, in-app scan, TestFlight
- [ ] **v0.4 Polish and integrations**: themes, EN / FA / RU interface, image OCR, MISP / OpenCTI, SIEM links
- [ ] **v0.5 Power features**: more providers, custom provider plugins, export formats
- [ ] **v1.0**: signed releases on all platforms, stable provider API, package managers
