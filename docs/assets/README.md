# Branding assets

| File | Use |
|---|---|
| `banner.png` (2560×1280) | README header |
| `social-preview.png` (1280×640) | GitHub → Settings → General → **Social preview** |
| `banner.svg` | Editable vector source (text is outlined, renders the same everywhere) |
| `logo/icon.svg`, `logo/icon-1024.png` | App icon (full-color, rounded square) |
| `logo/icon-mark.svg`, `logo/icon-mark-1024.png` | Icon without background (transparent) |
| `logo/icon-{512,256,128,64,48,32,16}.png` | Raster sizes |
| `logo/icon.ico` | Windows installer / executable icon |
| `logo/icon.icns` | macOS app icon |
| `logo/logo-horizontal-light.*` | Logo with white text (dark backgrounds) |
| `logo/logo-horizontal-dark.*` | Logo with dark text (light backgrounds) |
